# 🌱 IA no Agronegócio: o futuro da agricultura

> “A Inteligência Artificial transforma o campo em um espaço mais inteligente, produtivo e sustentável.”

## 📌 Sobre o projeto

Este projeto apresenta um quiz educativo sobre o uso da Inteligência Artificial no agronegócio.

O objetivo é mostrar, de maneira simples e interativa, como tecnologias inteligentes podem contribuir para o desenvolvimento da agricultura.

## 🤖 Temas abordados

- Inteligência Artificial no campo
- Agricultura de precisão
- Drones
- Sensores
- Análise de dados
- Clima
- Irrigação
- Sustentabilidade
- Produtividade
- Futuro do agronegócio

## 🌾 Objetivo

Demonstrar como a Inteligência Artificial pode ser utilizada como ferramenta de apoio ao produtor rural, ajudando na análise de informações e no planejamento das atividades agrícolas.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- JavaScript Modules
